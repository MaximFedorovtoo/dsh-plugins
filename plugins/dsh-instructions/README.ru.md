# Панель инструкций — загрузка AGENTS.md из интерфейса

Плагин для DSH, который добавляет страницу **«Инструкции»**: выберите локальный файл `.md`/`.txt` (или вставьте текст), проверьте его и сохраните как машинный файл инструкций **`$DSH_HOME/AGENTS.md`**. DSH читает этот файл в каждой сессии и в каждом проекте, поэтому загруженные правила действуют по умолчанию.

[English version](README.md)

## Что добавляется

| Место | Поведение |
|---|---|
| Боковая панель | Пункт **«Инструкции»** рядом с остальными панелями. |
| Страница | Показывает путь к файлу, есть ли он, размер, лимит и время последнего изменения. |
| Редактор | Моноширинное поле с текущим содержимым; изменения помечаются как несохранённые. |
| **Выбрать файл…** | Читает локальный `.md`/`.markdown`/`.txt` в браузере и вставляет текст в редактор. На диск пока ничего не пишется. |
| **Сохранить** | Отправляет текст на хост, который атомарно записывает `$DSH_HOME/AGENTS.md`. |
| **Отменить изменения** | Возвращает в редактор содержимое файла с диска. |
| **Удалить файл** | Удаляет файл инструкций (с подтверждением). |

Сама панель не работает с файловой системой: файлом владеют два аутентифицированных маршрута хоста (`GET`/`POST`/`DELETE /api/instructions`), а ограничение соединения DSH допускает к ним только владельца сессии.

## Установка

Пакет `dsh-instructions`, DSH 0.2.x, чистый JavaScript без зависимостей.

**Discover:** включите **Custom plugin indexes** на странице Plugins, добавьте индекс

```
https://raw.githubusercontent.com/MaximFedorovtoo/dsh-plugins/main/index.json
```

и установите **Instructions Panel**.

**Git:**

```powershell
dsh --% plugin --profile desktop add "github:MaximFedorovtoo/dsh-plugins#<commit>&path:/plugins/dsh-instructions"
```

**Локальная папка:** **Plugins → Add plugin** → абсолютный путь к `plugins/dsh-instructions`.

После установки перезапустите DSH: появится пункт в боковой панели, страница сможет прочитать текущий файл инструкций.

## Настройка

Строка `instructions` в `cordis.patch.yml` профиля (или в слое пакета):

```yaml
- id: instructions
  config:
    target: ''          # '' = <DSH_HOME>/AGENTS.md; относительный путь считается от DSH_HOME
    maxBytes: 65536     # лимит; совпадает с лимитом DSH (см. ниже)
```

## Размер файла

Штатный загрузчик инструкций DSH (`agent-instructions`) читает `$DSH_HOME/AGENTS.md` до **65 536 байт** по умолчанию. Панель использует тот же лимит, поэтому файл, принятый здесь, действительно загрузится целиком. Для файла большего размера поднимите оба лимита: `maxBytes` в строке `instructions` и `maxBytes` в строке `agent-instructions` профильного `cordis.patch.yml`.

## Как применяется файл

- `$DSH_HOME/AGENTS.md` — машинный слой инструкций DSH: его читает каждая новая сессия в любом проекте.
- Сохранение в панели действует на **новые сессии**; уже запущенная сессия остаётся со старыми инструкциями (откройте новый чат или перезапустите DSH, чтобы применить сразу).
- Проектный `AGENTS.md` по-прежнему главнее внутри своего проекта.
- Удаление файла не затрагивает проектные инструкции.

## Безопасность

- Маршруты доступны только владельцу сессии, другим браузерным пирам панель не видна.
- Запись атомарная (временный файл + переименование), поэтому прерванное сохранение не обрежет существующий файл.
- Плагин пишет ровно один путь и не сканирует/не меняет файлы проектов.

## Как проверить

1. Боковая панель → **Инструкции** → видно путь и состояние текущего файла.
2. Выберите свой `AGENTS.md` → **Сохранить** → бейдж покажет новый размер и время изменения.
3. Откройте новый чат: правила действуют. Файл на диске совпадает с содержимым редактора.

Самотест: `node test/instructions.test.mjs` проверяет дефолтный/относительный путь, состояние отсутствующего файла, атомарное сохранение и замену, отказ при пустом и слишком большом содержимом, удаление и регистрацию клиентской панели.
