# AGENTS.md — глобальные инструкции как устанавливаемый плагин

Пакет содержит мои правила работы в DeepSeek Harness и кладёт их в **`$DSH_HOME/AGENTS.md`** (на Windows `%USERPROFILE%\.dsh\AGENTS.md`). DSH подгружает этот файл автоматически в каждую сессию и в каждый проект, так что одни и те же правила действуют везде — копировать файл руками не нужно.

Сами инструкции — это файл [`AGENTS.md`](AGENTS.md); после установки его можно править под себя.

## Что делает

- При первой активации после установки плагин копирует вложенный `AGENTS.md` в `$DSH_HOME/AGENTS.md`.
- **Существующий другой файл не перезаписывается**, если не включено `overwrite: true`: инструкции — это пользовательские данные, плагин не должен молча их затирать.
- Запись атомарная (временный файл + переименование) и выполняется один раз за загрузку плагина.
- Удаление бандла не удаляет файл — он принадлежит пользователю.

## Установка

Три обычных способа, как у остальных плагинов репозитория (DSH 0.2.x):

**Discover:** включите **Custom plugin indexes** на странице Plugins, добавьте URL индекса

```
https://raw.githubusercontent.com/MaximFedorovtoo/dsh-plugins/main/index.json
```

и установите **AGENTS.md Instructions** из списка.

**Git:**

```powershell
dsh --% plugin --profile desktop add "github:MaximFedorovtoo/dsh-plugins#<commit>&path:/plugins/dsh-agents-md"
```

**Локальная папка:** **Plugins → Add plugin** → абсолютный путь к `plugins/dsh-agents-md`.

После установки перезапустите DSH: файл пишется при активации плагина, а новые инструкции применяются к следующим сессиям.

## Настройка

Строка `agents-md` в `cordis.patch.yml` профиля (или в слое пакета):

```yaml
- id: agents-md
  config:
    target: ''          # '' = <DSH_HOME>/AGENTS.md; относительный путь считается от DSH_HOME
    overwrite: false    # true — заменить существующий AGENTS.md
```

Через `target` можно указать другой глобальный файл инструкций:

```yaml
- id: agents-md
  config:
    target: 'instructions/my-rules.md'
    overwrite: false
```

## Обновление инструкций

С настройкой по умолчанию (`overwrite: false`) существующий файл остаётся как есть — это сделано намеренно. Чтобы получить новую версию вложенных инструкций, удалите `$DSH_HOME/AGENTS.md` перед перезапуском либо включите `overwrite: true` на один перезапуск и верните `false` обратно.

## Как проверить

- файл `$DSH_HOME/AGENTS.md` существует и совпадает с `plugins/dsh-agents-md/AGENTS.md`;
- после перезапуска в новой сессии инструкции видны в системном контексте;
- в логе DSH при первой загрузке есть `agents-md: installed …` или `agents-md: … already exists; left untouched`.

Самотест: `node test/agents-md.test.mjs` проверяет установку, отсутствие изменений при совпадении, сохранение чужого файла, замену при `overwrite: true` и разрешение относительного/дефолтного пути.

## Замечания

- Вложенные правила — мой личный рабочий процесс, а не требование DSH; прочитайте их перед включением.
- Имя и расположение файла соответствуют соглашению DSH: `AGENTS.md` в `$DSH_HOME` — машинный слой, проектный `AGENTS.md` всё равно главнее для своего проекта.
