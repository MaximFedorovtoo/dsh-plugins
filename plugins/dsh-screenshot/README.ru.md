# Скриншоты как ввод (`dsh-screenshot`)

Делает скриншот обычной частью разговора: вы прикрепляете картинку в поле
ввода, модель её читает, а ещё модель может сама посмотреть на экран или на
буфер обмена.

## Что добавляется

| Место | Поведение |
|---|---|
| Строка инструментов поля ввода | Одна кнопка-камера. Берёт картинку из буфера обмена (результат Win+Shift+S или любого «копировать изображение»); если в буфере картинки нет — открывает выбор файла самого поля ввода. Картинка становится обычным вложением черновика, поэтому работают штатные превью, допуск и отправка. Ctrl+V и drag-and-drop не меняются. |
| Лента вложений черновика | Заменяет штатное отображение. Клик по прикреплённой картинке открывает редактор разметки: кисть, стрелка, рамка и текст, шесть цветов, три толщины, отмена и очистка. Текстовое поле белое, с полоской для перемещения и штатным угловым грипом: тяните полоску — двигаете поле, тяните угол — меняете ширину и высоту (ширина задаёт перенос строк). **Применить** «сплющивает» разметку в PNG и подменяет вложение черновика; текст запроса вы пишете сами. Лента также сохраняет приём drag-and-drop (document-level слушатели, передающие файлы в `onAddFiles`) и показывает прогресс загрузки, повтор и удаление. |
| Инструмент агента `screenshot` | Снимает рабочий стол (все мониторы) или картинку из буфера и отдаёт модели настоящим блоком изображения. Необязательная обрезка `region`. |
| Инструмент агента `zoom_image` | Обрезает участок любого файла-изображения и увеличивает его (по умолчанию ×2, до ×4), чтобы мелкие подписи, значения и пометки на уменьшенном скриншоте стали читаемыми. Входной WebP декодируется через Windows Imaging Component. |
| Системный промпт | Короткий протокол «Reading screenshots»: сначала сказать, что на картинке; каждую пометку считать явным акцентом; увеличивать, а не угадывать; привязывать помеченный элемент к коду, который его рисует; задать один точный вопрос, если пометка неоднозначна; проверять результат по тем же доказательствам. |

## Установка

Пакет `dsh-screenshot`, версия 1.4.0, DSH 0.2.x. Чистый JavaScript, без
зависимостей и без сборки. Способы установки для Windows, macOS и Linux — в
инструкции репозитория: [INSTALL.md](../../INSTALL.md) (рус.) или
[INSTALL.en.md](../../INSTALL.en.md) (англ.). Коротко:

```sh
dsh plugin --profile desktop add 'github:MaximFedorovtoo/dsh-plugins#<commit>&path:/plugins/dsh-screenshot'
```

или добавьте индекс репозитория в **Plugins → Discover**:

```
https://raw.githubusercontent.com/MaximFedorovtoo/dsh-plugins/main/index.json
```

## Настройка

Строка в `cordis.patch.yml`:

```yaml
- id: screenshot
  config:
    cacheDir: ''          # по умолчанию <DSH_HOME>/cache/screenshot
    defaultZoomScale: 2
    maxZoomScale: 4
```

## Платформы

* **Снимок экрана и буфера работает только на Windows.** Оба инструмента
  агента (`screenshot` и `zoom_image`) используют Windows PowerShell 5.1 и
  `System.Drawing`/WPF, потому что хост Harness — обычный Node, где нет API
  захвата Electron. На macOS и Linux инструменты возвращают явную ошибку;
  кнопка в поле ввода, редактор разметки, вложения, drag-and-drop и вставка
  продолжают работать.
* `zoom_image` декодирует через GDI+, поэтому на Windows поддерживаются
  PNG/JPEG/GIF/WebP (WebP и другие форматы WIC сначала конвертируются в PNG).
* Кнопка-камера читает буфер через Clipboard API браузера, поэтому странице
  нужно разрешение на чтение буфера; если в буфере нет картинки, открывается
  выбор файла.
