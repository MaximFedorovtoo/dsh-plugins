# API Spend — расходы на API по проектам (`dsh-api-spend`)

Плагин для DeepSeek Harness: под полем ввода, в той же строке, где показаны
счётчики токенов, появляется пилюля с расходами на API в текущем проекте
(рабочей области). Клик открывает разбивку: сумма по каждому проекту,
потраченные токены, периоды «Сегодня / 7 дней / Всё время» и итоги с
официальной страницы платформы для сверки.

## Как считается

1. Хост-часть читает журналы всех сохранённых сессий (`ctx.sessionQuery`) и
   сворачивает отчёты провайдера о токенах: некэшированный ввод, чтение кэша,
   запись кэша, вывод. Повторная попытка (`llm/retry-started`) учитывается один
   раз. Каждый шаг относится к тому дню и тому ценовому окну (пик/вне пика), в
   которое он был выполнен.
2. Токены умножаются на официальные тарифы DeepSeek из конфигурации плагина и
   складываются по проектам. Проект — это рабочая область; сессии без
   воркспейса группируются по своему каталогу; субагентские сессии входят в
   проект родителя.
3. Отдельно запрашиваются официальные итоги аккаунта
   (`x-dsh-auth-token` из `ctx.deepseekAccount`): баланс, суммарные расходы за
   всё время и расходы за сегодня — они показываются в диалоге рядом со
   строками проектов.

## Тарифы

По умолчанию — официальные тарифы DeepSeek (USD за 1M токенов, часы пик):

| модель | кэш-хит | кэш-промах | вывод |
|---|---|---|---|
| `deepseek-flash` | 0.006 | 0.30 | 1.20 |
| `deepseek-v4-pro` | 0.044 | 1.32 | 3.96 |

Вне пика — половина (`offPeakFactor: 0.5`). Пик — будни 01:00–04:00 и
06:00–10:00 UTC; китайские праздники можно перечислить в `holidays`
(`YYYY-MM-DD`, пекинское время), тогда весь день считается вне пика.

Значения задаются в строке плагина `api-spend` в `cordis.patch.yml` профиля:

```yaml
- id: api-spend
  config:
    currency: USD
    symbol: '$'
    priceUnit: 1000000
    offPeakFactor: 0.5
    peakWindows: [{ start: 1, end: 4 }, { start: 6, end: 10 }]
    peakWeekdays: [1, 2, 3, 4, 5]
    holidays: []
    defaultModel: deepseek-flash
    models:
      deepseek-flash: { cacheHit: 0.006, cacheMiss: 0.3, output: 1.2 }
      deepseek-v4-pro: { cacheHit: 0.044, cacheMiss: 1.32, output: 3.96 }
    maxSessions: 400
    platformRefreshMs: 120000
```

- `models` — ставки по идентификатору модели, который сообщает провайдер;
- `defaultModel` — чья ставка берётся для неизвестной модели;
- `maxSessions` — сколько последних сессий учитывать в отчёте;
- `platformRefreshMs` — как часто перечитывать официальные итоги.

## Установка

Пакет `dsh-api-spend`, версия 1.1.0, DSH 0.2.x. Чистый JavaScript без
зависимостей и сборки; работает на Windows, macOS и Linux. Способы установки —
в инструкции репозитория: [INSTALL.md](../../INSTALL.md) (рус.) или
[INSTALL.en.md](../../INSTALL.en.md) (англ.). Коротко:

```sh
dsh plugin --profile desktop add 'github:MaximFedorovtoo/dsh-plugins#<commit>&path:/plugins/dsh-api-spend'
```

или добавьте индекс репозитория в **Plugins → Discover**:

```
https://raw.githubusercontent.com/MaximFedorovtoo/dsh-plugins/main/index.json
```

## Почему суммы на странице платформы могут быть больше

Страница `platform.deepseek.com/usage` показывает расходы **всех клиентов**
API-ключа (и других машин/приложений с тем же ключом). Строки проектов в
панели считают только сессии этого Harness. Итоги платформы в диалоге даны
для сверки и помечены отдельной строкой.

## Ограничения

- Аккаунт-провайдер (`deepseek-account`) нужен только для официальных итогов;
  без него панель показывает только расчёты по сессиям.
- Логи сессий, которые не читаются (старый формат, повреждённый хвост),
  пропускаются.
- Первый отчёт после запуска читает журналы сессий и может занять несколько
  секунд; дальше результаты кэшируются по ревизии журнала.
- Данные платформы отстают на несколько минут, поэтому свежий ход может
  появиться в официальных итогах позже, чем в расчёте по сессиям.
- Пилюля не показывается, пока за сегодня расходов нет.
