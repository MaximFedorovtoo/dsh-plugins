DeepSeek Harness — русская локализация (Windows), установщик без git
====================================================================

Что это
-------
Языковой пакет для веб-клиента DeepSeek Harness Desktop: 64 неймспейса,
2910 строк интерфейса и 545 названий/описаний плагинов. Установленное
приложение не изменяется: пакет копируется в профиль Desktop как штатный
клиентский плагин.

Язык появится в: Настройки → Общие → Язык → «Русский».
Если язык Windows русский, он выбирается автоматически.

Этот установщик — альтернатива установке через Plugins/Discover и git:
он не требует ни git, ни Node.js, ни прав администратора, ни сети.


Требования
----------
* Windows 10 или 11.
* Установленный DeepSeek Harness Desktop (0.2.x), запущенный хотя бы раз —
  чтобы существовал профиль %USERPROFILE%\.dsh\profiles\desktop.


Установка
---------
1. Распакуйте архив репозитория ЦЕЛИКОМ. Важно: файл Install-DSH-Russian.cmd
   должен лежать в папке windows-installer, а рядом — папки lib и
   windows-installer\patch-snippet.yml; скрипт ищет пакет на уровень выше.
2. Если архив скачан из интернета: правый клик по ZIP → «Свойства» →
   «Разблокировать» (Unblock) → ОК.
3. Закройте DeepSeek Harness или оставьте открытым — не критично.
4. Двойной клик по Install-DSH-Russian.cmd и дождитесь надписи Done.
   Скрипт:
     - скопирует пакет в %USERPROFILE%\.dsh\profiles\desktop\plugins\dsh-locale-ru;
     - добавит одну строку в cordis.patch.yml (резервная копия — рядом).
5. Откройте DeepSeek Harness. Если интерфейс остался английским — нажмите
   Ctrl+R в приложении или перезапустите его.
6. Настройки → Общие → Язык → «Русский» (если ещё не выбран).

Если профиль не найден: запустите DeepSeek Harness один раз, закройте и
повторите установку. Если используется нестандартный DSH_HOME, задайте
переменную окружения DSH_HOME — скрипт её учитывает.


Удаление
--------
Двойной клик по Uninstall-DSH-Russian.cmd. Язык вернётся к английскому сразу
после перезагрузки профиля (Ctrl+R или перезапуск приложения).


Важно: не устанавливайте локализацию двумя способами одновременно
-----------------------------------------------------------------
Если пакет уже подключён через Plugins/Discover или git, этот установщик
добавит второе подключение того же клиентского модуля, и DSH откажется его
загружать из-за конфликта источников. Сначала удалите прежнюю установку
(карточка плагина → Remove или dsh plugin remove dsh-locale-ru), затем
запускайте этот скрипт.


Ручная установка (если .cmd не запускается)
-------------------------------------------
1. Скопируйте файлы пакета (package.json и папку lib) в:
   %USERPROFILE%\.dsh\profiles\desktop\plugins\dsh-locale-ru
2. В конец файла %USERPROFILE%\.dsh\profiles\desktop\cordis.patch.yml
   добавьте строки из patch-snippet.yml:

   # Russian language pack - client plugin.
   - insert:
       - id: locale-ru
         name: ./plugins/dsh-locale-ru/lib/index.js

3. Сохраните файл в UTF-8 без BOM и перезапустите DeepSeek Harness.


Ограничения
-----------
* Переведены интерфейс клиента и метаданные плагинов. Нативные меню Electron,
  окно приветствия и диалоги обновления остаются на английском/китайском:
  они запечатаны внутри приложения.
* Новые строки DSH после версии 0.2.1-rc.3 показываются на английском —
  интерфейс не ломается.


Безопасность
------------
Скрипты не обращаются к сети, не требуют прав администратора и не меняют
файлы приложения: только копируют пакет в профиль пользователя и добавляют
строку в его cordis.patch.yml. Их можно открыть блокнотом и проверить.
