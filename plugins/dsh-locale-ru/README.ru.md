# Русская локализация DeepSeek Harness

Языковой пакет для веб-клиента [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) (DSH): полный русский перевод интерфейса — **64 неймспейса, 2910 строк интерфейса и 545 названий/описаний плагинов**. Установленное приложение не изменяется: пакет подключается к профилю как штатный клиентский плагин и регистрирует словари через публичный API `ctx.locale`.

Язык появляется в **Настройки → Общие → Язык → «Русский»**. Если язык Windows русский, он выбирается автоматически.

[English version](README.md) · [Инструкция по установке](INSTALL.md)

## Требования

- DeepSeek Harness **0.2.x** (пакет собран по 0.2.1-rc.3), поверхность Web/Desktop.
- Для установки из git — `git`; для установщика `.cmd` — Windows 10/11 и ничего больше (ни Node.js, ни Python, ни прав администратора).

## Установка — коротко

Подробно, со всеми способами и диагностикой — [INSTALL.md](INSTALL.md).

**Discover:** Plugins → включить **Custom plugin indexes** → Discover → Add index source:

```
https://raw.githubusercontent.com/MaximFedorovtoo/dsh-plugins/main/index.json
```

**Git** (любая ОС, нужен `git`):

```powershell
dsh plugin --profile desktop add 'github:MaximFedorovtoo/dsh-plugins#<commit>&path:/plugins/dsh-locale-ru'
```

В PowerShell используйте `dsh --% plugin --profile desktop add "..."` — иначе `&` в адресе съедается обёрткой `dsh.cmd` (подробно в [INSTALL.md](INSTALL.md)).

**Установщик для Windows (без git):** запустить `windows-installer\Install-DSH-Russian.cmd` (двойной клик), дождаться `Done`, перезапустить DSH или нажать Ctrl+R.

**Локальная папка:** Add plugin → абсолютный путь к папке плагина `plugins\dsh-locale-ru` в распакованном репозитории.

Устанавливайте **только одним способом**. Если пакет уже стоял через `.cmd`, сначала запустите `windows-installer\Uninstall-DSH-Russian.cmd`, потом ставьте через Plugins/Discover: два одновременных подключения одного и того же клиентского модуля DSH отвергает как конфликт источников.

## Что переведено

- Интерфейс клиента: 64 неймспейса — чат, настройки, плагины, задачи, Codex, голосовой ввод, сайдбар, диалоги, ошибки, подсказки.
- Названия и описания плагинов (545 строк): пакет расширяет `ctx.locale.resolveText`, поэтому метаданные плагинов, приходящие с хоста строками или картами `{en, zh}`, тоже показываются по-русски.

## Ограничения

- Нативные меню Electron, окно приветствия и диалоги обновления остаются на английском/китайском: они запечатаны внутри приложения и не поддерживают смену языка.
- Внешние индексы маркетплейса, технические идентификаторы пакетов и пресетов, ответы модели и автогенерируемые заголовки сессий остаются как есть.
- Пакет собран по версии 0.2.1-rc.3. На других версиях новые строки DSH показываются на английском — интерфейс не ломается. Обновление перевода требует исходного каталога генератора (`work/extract_all.py` и далее), в этот репозиторий он не входит.

## Удаление

- Установка через Plugins/Discover: карточка плагина → **Remove** (или `dsh plugin --profile desktop remove dsh-locale-ru`).
- Установка через `.cmd`: `windows-installer\Uninstall-DSH-Russian.cmd`.

После удаления нажмите Ctrl+R или перезапустите DSH — интерфейс вернётся к английскому.

## Как это проверено

- `lib/client.js` — рабочий бандл, который уже используется: установленная копия в профиле побайтово совпадает с файлом репозитория, и интерфейс DSH на этой машине работает по-русски.
- Бандл исполняется в заглушке `window.__ModuleLoader__.load` и регистрирует язык и все словари без исключений; id регистрации совпадает с именем пакета.
- Пакет ставится как bundle через `dsh plugin add` (проверено на временном профиле) и собирается в `dsh --profile <name> --dump-config` строкой `id: locale-ru`.
