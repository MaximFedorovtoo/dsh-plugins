# dsh-voice-ru — русский голосовой ввод для DeepSeek Harness

Одна кнопка-микрофон в строке ввода — там, где раньше был встроенный микрофон превращает надиктованные тезисы в
связную задачу с учётом контекста проекта:

1. Нажмите **«Голосом»** и надиктуйте тезисы по-русски.
2. После ~1,2 с тишины запись остановится сама (повторный клик — остановить
   вручную).
3. Речь распознаётся локально (GigaAM-v3), тезисы превращаются в одну связную
   задачу — цель, требования, ограничения, критерии готовности — с учётом
   контекста проекта (рабочая папка, `AGENTS.md`, файлы в корне, последние
   сообщения чата).
4. Задача вставляется в поле ввода. Вы её читаете, при необходимости правите и
   **отправляете сами**. Автоотправки нет.

Кнопка **«В задачу»** делает то же самое для уже набранного или надиктованного
текста в поле: формирует задачу и оставляет её в поле для проверки.

## Движки

| Движок | Модель | Размер | Пунктуация | Скорость |
|---|---|---|---|---|
| `ctc` (по умолчанию) | GigaAM-v3 CTC int8 через sherpa-onnx | ~214 МБ | нет | очень быстро на CPU |
| `e2e` | GigaAM-v3 e2e_rnnt через Python/PyTorch | ~2,5 ГБ окружение + кэш | есть, с нормализацией | медленнее, нужен Python |

Оба движка работают полностью офлайн. Для e2e нужно отдельное окружение Python
(PyTorch + transformers) — пошаговая установка в [INSTALL.md](INSTALL.md);
для CTC достаточно зависимости `sherpa-onnx-node`, модель скачивается в
`%USERPROFILE%\.dsh\speech-to-text\gigaam`.

Если окружение e2e отсутствует или падает, плагин автоматически откатывается на
CTC — голосовой ввод продолжает работать.

## Установка

```powershell
dsh plugin --profile desktop add https://github.com/MaximFedorovtoo/dsh-plugins/tree/main/plugins/dsh-voice-ru
dsh plugin --profile desktop add sherpa-onnx-node
```

Перезапустите DSH. Чтобы осталась ровно одна кнопка-микрофон, можно отключить
встроенный voice-input bundle (см. INSTALL.md).

## Настройка

```yaml
- id: voice-ru
  config:
    engine: ctc            # 'ctc' или 'e2e'
    dataRoot: ""           # папка модели CTC, по умолчанию <DSH_HOME>/speech-to-text/gigaam
    modelDirectory: ""     # готовая папка с model.int8.onnx + tokens.txt
    e2ePython: ""          # python.exe из venv для e2e
    e2eHfHome: ""          # HF-кэш для e2e, только ASCII-путь
    e2eModel: ai-sage/GigaAM-v3
    e2eRevision: e2e_rnnt
    llmProvider: deepseek-account
    llmModel: deepseek-flash
    maxTokens: 1200
    contextMessages: 8
    enableDebug: false
```

## Ограничения

- GigaAM — русскоязычная модель.
- e2e тяжелее для CPU и требует ASCII-путь к HF-кэшу на Windows (sentencepiece
  не открывает `tokenizer.model` по пути с кириллицей).
- Качество сформированной задачи зависит от выбранного LLM-маршрута.
- Разрешение на микрофон запрашивает браузер; записи уходят только локальному
  хосту, не в облако.
